AI production system

A set of AI agents I built so one person can supply creatives and product imagery to many stores, without letting quality slip.

Tools
Claude Code, VS Code
Used for
Ads, catalogs, landing pages
Role
Design and build

One product, every angle

Each catalog product gets a studio shot, a lifestyle scene and an in-use shot, all showing exactly the same product and personalisation.

The problem

Many stores, many products and many campaigns, each needing images that are accurate, on-brand and fast to produce. Doing it all by hand would mean either slow output or slipping quality.

How it works

Generate. An image-generation agent runs on Higgsfield and Magnific, working from structured briefs, with reference images to keep product details and characters accurate.

Check. A QA agent reviews every batch against a checklist before it goes out, catching product errors that are easy to miss by eye. It also checks images already live on product and blog pages, so the whole site stays consistent with our real product details. It reached about 90% accuracy in testing.

Learn. A performance-review workflow flags which creatives to scale or retire, based on the metrics a creative actually controls.

The workflow lives in shared skill files, so any coding agent that can read them, such as Claude Code or Codex, can run it.

What it produced

Detail-accurate catalog imagery for Meta shopping ads: over 60 customised home and gift products across three European stores. Each image had to stay true to the real product’s materials, edges and finish.

The same approach powers the campaign landing pages I design and build with Claude Code, including the images and copy on them.
